# Player Data Import

Initial player data is seeded from Sleeper's public NFL player endpoint, then enriched with the DynastyProcess/nflverse fantasy player ID crosswalk.

Run:

```sh
node scripts/import_sleeper_players.mjs
node scripts/import_dynastyprocess_playerids.mjs
node scripts/load_player_database.mjs
```

Outputs:

- `data/raw/sleeper_players_raw.json`: unmodified Sleeper response for audit/debugging.
- `data/normalized/players.json`: canonical player table for application use.
- `data/normalized/players.csv`: canonical player table for inspection.
- `data/normalized/player_external_ids.json`: source-specific ID mappings.
- `data/normalized/player_external_ids.csv`: source-specific ID mappings for inspection.
- `data/normalized/sleeper_external_id_conflicts.json`: Sleeper source IDs quarantined because the same external ID appeared on multiple canonical players.
- `data/normalized/sleeper_import_summary.json`: import counts and output metadata.
- `data/raw/dynastyprocess_playerids.csv`: raw DynastyProcess crosswalk for audit/debugging.
- `data/normalized/dynastyprocess_playerids.json`: parsed DynastyProcess crosswalk.
- `data/normalized/dynastyprocess_unmatched_playerids.json`: crosswalk rows that did not match the canonical player table.
- `data/normalized/dynastyprocess_match_conflicts.json`: crosswalk match conflicts and external IDs skipped because they already belonged to another canonical player.
- `data/normalized/dynastyprocess_import_summary.json`: crosswalk import counts and output metadata.
- `data/db/fantasy_football_agent.sqlite`: queryable SQLite database loaded from normalized player data.
- `data/db/load_player_database_summary.json`: database load counts and metadata.
- `data/projections/templates/`: copyable JSON and CSV projection import templates.
- `data/projections/samples/`: known-good sample projection imports for testing.
- `data/projections/*_merged.json`: projection import outputs generated by `npm run projection:import`.

Notes:

- `player_id` is an internal deterministic ID based on the Sleeper source ID for this first seed.
- GSIS, Yahoo, ESPN, Sportradar, FantasyData, MFL, Fleaflicker, FantasyPros, and other IDs are stored as external IDs.
- The DynastyProcess import matches existing players by Sleeper ID first, then GSIS and other existing external IDs.
- Run the Sleeper import before the DynastyProcess import when rebuilding from scratch.
- Run the database loader after both imports to refresh the SQLite database.
- Raw source data is preserved so future imports can be audited against the normalized tables.
- Projection import details are documented in `docs/PROJECTION_IMPORT.md`.
